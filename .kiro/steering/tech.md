# 作るものの技術的な決まり

- 作るツールは、**ブラウザで開くだけで動く HTML ファイル1枚** にしてください（HTML・CSS・JavaScript を1ファイルにまとめる）
- 利用者の PC には何もインストールできません。Node.js、Python、ビルド作業、サーバーは使わないでください
- 外部のライブラリや CDN、外部サイトへの通信は使わないでください（ネットワークが制限された PC や、オフラインでも動くようにするため）
- CSV は、利用者が画面の「ファイルを選択」で選んだものを読み込んでください。UTF-8 を基本とし、Excel で保存した Shift_JIS にも対応できると望ましいです
- 画面の文言はすべて日本語にしてください
- コードには、プログラムを知らない人が読んでも流れが分かる程度の日本語コメントを入れてください
