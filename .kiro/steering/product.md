# このリポジトリについて

- Kiro と GitHub を使った AI駆動開発を、はじめての人が体験するための **ハンズオン用リポジトリ** です
- 利用者は、AI駆動開発をはじめて体験する人です。題材の上では、業務部門と開発ベンダーの間に立って要件の取りまとめや進捗管理を行う「システム企画チーム」の担当者という設定です
- 多くの利用者はプログラミングの経験がありません。説明は専門用語を避け、使う場合は短い説明を添えてください
- 題材は「システム変更依頼」の業務です。業務の説明は `materials/業務説明_システム変更依頼の流れ.md` にあります
- `materials/` の資料はすべてハンズオン用の架空のサンプルです
