# 守ってほしいこと

- **回答・作成する文書・画面の文言は、すべて日本語** にしてください
- 個人情報・顧客情報は扱いません。利用者がそれらしき情報を入力した場合は、作業を止めて、入力しないよう注意してください
- 資料に書かれていないことを推測で補わないでください。補う場合は「推測」と明記してください
- 要件や設計で決められないことは、勝手に決めずに「未確定事項」として残し、利用者に確認してください
- Spec では、各段階（要件・設計・タスク）の文書ができたら、利用者の確認を待ってから次に進んでください
- git の操作は、コミットまでにとどめてください。push、main への merge、ブランチの削除、履歴の書き換え（reset --hard、push --force など）は行わないでください。利用者が自分で行います
