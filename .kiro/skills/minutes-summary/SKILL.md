# 議事録整理スキル

議事録を、定例の報告にそのまま使える形に整理する。

## 手順

1. 渡された議事録を最後まで読む。議事録が渡されていなければ、どのファイルかを利用者に聞く
2. 次の3つに分けて整理する
   - **決まったこと**：合意・決定した内容。案件の ID があれば先頭に書く
   - **持ち越し**：結論が出ず次回以降に回った内容と、その理由
   - **ToDo**：担当・期限を表にする。議事録に書かれていない項目は「未記載」とし、推測で埋めない
3. 「確認が必要な点」として、議事録の中で矛盾している点やあいまいな点があれば最後に挙げる
4. 結果を `participants/＜名前＞/議事録整理_＜議事録の日付＞.md` に保存する。＜名前＞は今のブランチ名 `practice/＜名前＞` から判断し、分からなければ利用者に聞く

## 出力の形

```markdown
# 議事録整理：＜会議名＞（＜日付＞）

## 決まったこと
- 

## 持ち越し
- 

## ToDo
| No | 内容 | 担当 | 期限 |
|---|---|---|---|

## 確認が必要な点
- 
```

## 守ること

- 議事録に書かれていないことを補わない
- 個人名が書かれていても、出力では部署名・会社名だけにする
