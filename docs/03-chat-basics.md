# STEP 3 チャットに慣れる（60分）

## この回の目的

- Kiro のチャットに資料を渡して、要約・質問・点検をさせられるようになる
- 「良い頼み方」と「ふつうの頼み方」で結果が変わることを体感する

> この回ではファイルを変更しません。AIに「読ませて答えさせる」だけです。

## 準備するもの

- Kiro でこのリポジトリを開いていること（STEP 2）
- 画面左下が `practice/自分の名前` ブランチになっていること

---

## チャットの基本操作

1. キーボードで **`Ctrl` + `L`** を押し、右側にチャット欄を開く（画面右上のチャットの切り替えボタンでも開けます）
2. チャット欄の下の入力欄に依頼を書いて Enter（改行したいときは `Shift` + `Enter`）
3. 資料を渡すには、入力欄で **`#`** を入力し、出てくる候補から **File** を選んでファイル名を選ぶ
   - 左側のファイル一覧から、ファイルを入力欄へドラッグしても渡せます
4. 新しい話題を始めるときは、チャット欄上部の **「+」（新しいセッション）** を押す
   - 話題を混ぜないほうが、AIの答えが正確になり、クレジットも節約できます

> Kiro がファイルの書き換えやコマンドの実行をしようとすると、**許可を求める表示** が出ます。この回では「読むだけ」なので、書き換えの許可を求められたら **拒否** してください。

## 演習

### 演習1 要約させる（10分）

入力欄にそのまま貼り付けて送ってください。

```
#materials/議事録_サンプル_変更依頼定例.md を読んで、3行で要約してください。
```

> `#` の部分は、実際には上の「基本操作3」でファイルを選んでください。以降の演習も同じです。

### 演習2 頼み方を変えて比べる（15分）

同じ議事録を、今度は次の頼み方で依頼します。新しいセッションを開いてから送ってください。

```
あなたは業務部門とベンダーの間を取りまとめる担当者のアシスタントです。
#materials/議事録_サンプル_変更依頼定例.md を読んで、次の形で整理してください。

1. 決まったこと（箇条書き）
2. 決まっていないこと・持ち越し（箇条書き）
3. ToDo（担当・期限を表にする。議事録に書かれていない場合は「未記載」と書く）

推測で補わず、議事録に書いてあることだけを使ってください。
```

**比べてみましょう。** 演習1と何が違いましたか？
良い頼み方の型は **「役割・資料・ほしい形・守ってほしいこと」** の4つです（[プロンプト集](prompts.md) にもあります）。

### 演習3 AIに質問させる（15分）

AIに答えを出させるのではなく、**抜けや矛盾を指摘させる** 使い方です。要件をまとめるときに一番役に立ちます。

```
#materials/ベンダー依頼文_下書き_サンプル.md は、業務部門からの依頼をベンダーに伝える文書の下書きです。
ベンダーがこれを読んで見積もりや作業を始めるとしたら、情報が足りない点・あいまいな点を、
ベンダーの立場から質問の形で10個挙げてください。重要な順に並べてください。
```

### 演習4 複数の資料を突き合わせる（15分）

```
#materials/議事録_サンプル_変更依頼定例.md と #materials/変更依頼一覧_サンプル.csv を突き合わせて、
議事録の内容と一覧表で食い違っている点があれば、表にしてください。
列は「依頼ID」「議事録の記載」「一覧表の記載」「どちらが正しそうか・確認先」にしてください。
```

> このサンプル資料には、わざと食い違いを3か所ほど仕込んであります。AIはいくつ見つけたでしょうか。
> 見つからなかったものがあれば、「他にもないか、もう一度確認して」と続けて頼んでみましょう。

### ふりかえり（5分）

- 業務で一番使えそうだと思った演習はどれか
- AIの答えで「そのまま使うと危ない」と思った点はあったか（AIは間違えることがあります。最後に確認するのは人間です）

## 困ったとき

- 英語で返ってくる → このリポジトリには「日本語で答える」ルールを入れてありますが、それでも英語になる場合は「日本語で答えてください」と付け足す
- 答えが途中で止まった → 「続けてください」と送る
- 何をしても反応しない → [困ったとき集](troubleshooting.md) の「チャットが反応しない」

- 「なるべく早く」で期限が分からない
- 「今と同じように」の基準がない
- 件数・データ量が分からない
- テストの範囲と受け入れ基準がない
- 問い合わせ先が書かれていない
