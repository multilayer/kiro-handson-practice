# Kiro ハンズオン用リポジトリ

Kiro と GitHub を使った AI駆動開発を、はじめての人が **ひとりで、一歩ずつ** 体験するためのハンズオン用リポジトリです。
**ここにある資料は、すべてハンズオン用に作った架空のサンプルです。** 失敗しても誰にも迷惑はかからないので、安心して触ってください。

> このリポジトリは、**自分の GitHub アカウントにコピーして使う** 前提で作っています。
> Kiro の環境（アカウント・プラン）も、自分で用意してください。用意のしかたは [STEP 0 始める前の準備](docs/00-environment.md) にあります。

全体の流れは、先に [スライド（PDF）](slides/kiro-handson-slides.pdf) でつかんでおくと進めやすくなります。勉強会などで使う人向けに、編集できる [PowerPoint 版](slides/kiro-handson-slides.pptx) も置いています。

---

## このハンズオンで身につくこと

1. GitHub の見方を知り、Kiro にリポジトリを取り込む
2. Kiro のチャットで文書を読ませる・質問する・直させる。失敗したら戻す
3. Steering（AIへの前提説明）と Hooks（決まりごと）で、AI の動きをそろえる
4. Spec（仕様駆動開発）で「要件 → 設計 → タスク → 実装」を AI と進める
5. 作ったものをプルリクエストで見直し（セルフレビュー）、取り込む（マージ）
6. AI と対話しながら、その場で要件を決める（モブ演習。ひとりでも、仲間とでもできます）
7. スキルで手順を覚えさせ、MCP で外の道具をつなぐ（応用編）
8. AI-DLC ワークフローで、AI の進行に沿って試作を1本通す（上級編）

## フォルダの中身

```
kiro-handson-practice/
├─ README.md            … このファイル
├─ docs/                … 手順書（STEP 0〜10）、ひとりで進めるときのガイド、用語集、プロンプト集、困ったとき集、勉強会ガイド
├─ materials/           … ハンズオンで使う架空の業務資料（議事録・業務説明・一覧表など）
├─ exercises/           … STEP 6〜8・10 の演習のお題
├─ examples/            … 完成見本（自分でやった後に見比べる用）
├─ slides/              … 全体をつかむためのスライド（PDF・PowerPoint）

   ├─ hooks/             … Hooks（STEP 5 で自分で作る）
   └─ skills/            … スキル（STEP 9 で使う）
```

## 必ず守るルール

- **個人情報・顧客情報は絶対に入れない。** Kiro のチャットにも、このリポジトリにも入れません
- **練習ではここにあるサンプル資料だけを使う。** 仕事の資料や、人から預かった資料は使いません
- **迷ったら手を止める。** 「入れてよいか分からない」「許可してよいか分からない」ときは、入れない・許可しないのが正解です
- **main ブランチは直接変更しない。** 自分用のブランチで作業し、プルリクエストで取り込みます（STEP 2 で説明します）
- **パスワード・API キー・アクセストークンなどの秘密情報も入れない。** 画面のメッセージを貼るときも、写り込んでいないか確かめます

## 前提と注意

- 手順書の画面表記・料金・モデル名などは **2026年10月時点** のものです。Kiro・GitHub・AI-DLC は更新が速いので、表示が違うときは各公式サイトで最新の情報を確認してください
- 手順書は Windows の PC を前提に書いています。Mac の場合は、`Ctrl` を `Cmd` に、PowerShell を「ターミナル」に読み替えてください（STEP 10 のインストール手順は Windows 向けです）
- Kiro の利用には、Kiro の利用規約が適用されます。有料プランの料金は自分の負担になります
