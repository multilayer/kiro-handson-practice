# STEP 10（上級編）のお題：AI-DLC ワークフローで定例用サマリーを作る

> ハンズオン用の架空の依頼です。手順は [STEP 10 上級編](../../docs/10-aidlc-workflows.md) を見てください。

このフォルダは、AI-DLC ワークフローを試すための **持ち出し用のセット** です。
ハンズオン用リポジトリの中では作業せず、自分の作業フォルダ（例：`C:\Users\＜自分＞\kiro\aidlc-taro`）にコピーしてから使います。

| ファイル | 中身 | 誰が読むか |
|---|---|---|
| `vision.md` | 何を・誰のために作るか、最初の版でやること・やらないこと | AI-DLC（最初の依頼で読ませる） |
| `technical-environment.md` | 作るものの形、使わないもの、テストの考え方、守ること | AI-DLC（最初の依頼で読ませる） |
| `README.md` | このファイル | 自分（利用者） |

コピーするときに、`materials/変更依頼一覧_サンプル.csv` も同じフォルダに入れます。

## なぜリポジトリの外で作業するのか

AI-DLC を入れると、フォルダの中に `.kiro/`（AI-DLC 用のエージェントやフック）、`aidlc/`（作業記録）、`AGENTS.md` などがまとめて作られます。
ハンズオン用リポジトリの中で入れると、STEP 5・9 で使った Steering やスキルと混ざってしまうため、**自分専用の空のフォルダ** で試します。

## 作業を始める前に考えておくこと

AI-DLC は最初に質問をしてきます。答えに迷わないよう、次を自分なりに考えておきましょう（正解はありません）。

- 「進行中」に含めるのは、どのステータス？（CSV には `受付` `見積中` `開発中` `テスト中` `完了` があります）
- 「取り下げ」の依頼が出てきたら、どう数える？
- 「近い」は30日以内でよい？ 基準日は今日？
- 定例で映すとき、一番上に何があるとうれしい？
